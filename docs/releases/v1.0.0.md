# Xave 1.0.0

The first release. A self-hosted notebook for one person or several: workspaces, nested folders,
notes, file attachments, a task list, a trash, and a vault that seals note bodies in the browser
before they are sent.

## Highlights

- Workspaces, nested folders, notes, file attachments and tasks in one application, per account.
- One search across every workspace of an account, from the header, with each result naming the
  workspace it came from.
- A browser-side vault: note bodies are sealed with AES-GCM under a passphrase stretched with
  PBKDF2-SHA256 at 600,000 iterations. The server stores ciphertext, the parameters and one sealed
  check value it can neither read nor forge.
- Light and dark themes, and six palettes, over a single design-token layer.
- Account isolation: every row is scoped to its owner, with a test that proves one account cannot
  read or write another account's rows.

## Requirements

PHP 8.2 or newer with the `pdo_sqlite` and `zip` extensions, Composer, Node 20 or newer, npm.
SQLite by default; the migrations are portable to MySQL or PostgreSQL.

## Install

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install && npm run build
php artisan serve
```

## Notes and limits

- Attachment bytes are not sealed by the vault. The upload path records that rather than claiming
  otherwise.
- While the vault is on, a search matches titles and file names only, because the server holds
  ciphertext.
- Losing the passphrase means losing those note bodies, by design.

## Tests

`php artisan test` covers every endpoint group, the soft-delete and purge paths, and cross-account
isolation. The same suite runs in CI on every push to `main`.
